# Формат описания устройств Modbus — `modbus-regmap/1.0`

Один файл = один прибор (один slave-адрес). Файл лежит в репозитории в
`devices/regmaps/`, на устройстве — в `/lfs/regmaps/`, расширение `.jsonc`.

**Синтаксис:** JSON с комментариями (`//`, `/* */`) и висячими запятыми.
Интерпретатор нормализует файл в строгий JSON и валидирует по этой схеме.
Пропущенные запятые — ошибка; `tools/regmap/jsonc.py --fix` умеет их починить.

---

## 1. Верхний уровень

```jsonc
{
  "format": "modbus-regmap/1.0",     // обязателен, по нему выбирается поведение
  "device":   { ... },               // обязателен
  "transport":{ ... },               // обязателен
  "enums":    { ... },               // необязателен
  "groups":   [ ... ],               // обязателен
  "commands": [ ... ],               // необязателен
  "alarms":   [ ... ],               // необязателен
  "ui":       { ... }                // необязателен
}
```

### `device`

| Поле | Тип | Обяз. | Смысл |
|---|---|---|---|
| `id` | строка | да | стабильный идентификатор профиля, латиницей: `innovert.isd222` |
| `vendor` | строка | да | производитель |
| `model` | строка | да | модель |
| `series` | строка | нет | серия/линейка |
| `revision` | строка | нет | ревизия описания (например, версия мануала) |
| `note` | строка | нет | свободное описание |

### `transport`

| Поле | Тип | По умолч. | Смысл |
|---|---|---|---|
| `protocol` | `modbus-rtu` \| `modbus-ascii` \| `modbus-tcp` | `modbus-rtu` | протокол |
| `defaults.address` | 1..247 | — | адрес прибора по умолчанию |
| `defaults.baud` | число | — | скорость |
| `defaults.parity` | `none` \| `even` \| `odd` | `none` | чётность |
| `defaults.stopbits` | `1` \| `2` | `1` | стоп-биты |
| `defaults.timeout_ms` | число | 500 | таймаут ответа |
| `defaults.retries` | число | 0 | повторы при таймауте |
| `limits.max_regs_per_read` | число | 125 | лимит прибора на один FC3/FC4 |
| `limits.max_regs_per_write` | число | 123 | лимит на один FC16 |
| `byte_order` | `ABCD`\|`CDAB`\|`BADC`\|`DCBA` | `ABCD` | порядок слов в многорегистровых значениях |
| `register_base` | `0` \| `1` | `0` | 1 = адреса в описании на единицу больше PDU |
| `functions.read` | число | 3 | код функции чтения регистров |
| `functions.write_one` | число | 6 | код записи одного регистра |
| `functions.write_many` | число | 16 | код записи нескольких регистров |

Порядок слов: `ABCD` — как в стандарте (старшее слово первым, байты старший-первым),
`CDAB` — слова переставлены, `BADC` — байты переставлены внутри слов, `DCBA` — полный реверс.

### `enums`

```jsonc
"enums": {
  "innovert.fault": [ { "v": 0, "t": "Без ошибок" },
                      { "v": 2, "t": "oc1 — перегрузка по току при ускорении" } ]
}
```
Имена свободные, рекомендуется `<профиль>.<смысл>`. Значения `v` уникальны внутри словаря.
Регистр ссылается на словарь полем `enum`.

## 2. Группы и регистры

```jsonc
"groups": [
  { "id": "PB", "name": "Базовые функции", "order": 1, "registers": [ ... ] }
]
```
`order` задаёт порядок вывода; при отсутствии — по порядку в файле.

### Поля регистра

| Поле | Тип | Обяз. | Смысл |
|---|---|---|---|
| `addr` | число | да | адрес PDU (без сдвига, сдвиг — в `transport.register_base`) |
| `name` | строка | да | короткое имя (колонки, плитки) |
| `desc` | строка | нет | полное описание, подсказка |
| `access` | `R`\|`RW`\|`W`\|`WO` | да | доступ по Modbus |
| `write` | объект | нет | как писать: `{ "mode": "direct" \| "command" }`, по умолчанию `direct` |
| `type` | см. ниже | да | тип значения |
| `count` | число | нет | число 16-битных регистров (нужно для `string`, `struct`, массивов) |
| `byte_order` | строка | нет | переопределяет `transport.byte_order` |
| `enum` | имя словаря или массив | нет | расшифровка значения |
| `enum_from` | `{ "addr": N }` | нет | словарь берётся у другого регистра |
| `bits` | массив | нет | битовые поля, см. ниже |
| `bcd` | массив чисел | нет | разбивка по полубайтам, напр. `[2,2]` → `1.10` |
| `fields` | массив | нет | поля составного значения (`struct`, `time`), см. ниже |
| `value` | объект | нет | преобразование и оформление значения |
| `default` | число/строка | нет | значение по умолчанию **в инженерных единицах** |
| `volatile` | bool | нет | значение меняется само (телеметрия) |
| `poll` | `fast`\|`slow`\|`on-demand`\|`never` | нет | класс опроса (по умолчанию `slow`) |
| `visible_if` | условие | нет | показывать только при выполнении |
| `enable_if` | условие | нет | разрешать правку только при выполнении |
| `tags` | массив строк | нет | метки для интерпретатора: `gauge`, `chart`, `hidden`, `service` |

### Типы (`type`)

| Тип | Регистров | Смысл |
|---|---|---|
| `u16`, `s16` | 1 | целое 16 бит без знака / со знаком |
| `u32`, `s32` | 2 | целое 32 бита |
| `u64`, `s64` | 4 | целое 64 бита (счётчики энергии) |
| `f32`, `f64` | 2 / 4 | IEEE 754 |
| `bcd` | 1 | двоично-десятичное, разбивка в `bcd` |
| `bits` | 1 (или больше) | набор битовых полей в `bits` |
| `string` | `count` | строка, байты в порядке слов `byte_order` |
| `time` | `count` | дата/время из полей `fields` |
| `struct` | `count` | произвольное составное из `fields` |

### `value` — преобразование и оформление

| Поле | Смысл |
|---|---|
| `scale` | **множитель**: `инженерное = raw * scale + offset`. Для «делить на 10» → `0.1` |
| `offset` | смещение |
| `unit` | единица измерения |
| `decimals` | сколько знаков показывать |
| `min`, `max` | границы в инженерных единицах |
| `min_from`, `max_from` | границы берутся из другого регистра: `{ "addr": 106 }` |
| `step` | шаг для полей ввода |
| `format` | шаблон вывода, напр. `"v{X}.{Y}"` для BCD-версии |

Порядок обработки: **слова → декодирование типа (с учётом `byte_order` и `count`) →
`raw * scale + offset` → расшифровка (`enum`/`bits`/`bcd`/`fields`) → оформление
(`decimals`, `format`, `unit`)**.

### `bits` — битовые поля

```jsonc
"bits": [
  { "mask": 1,  "name": "FWD" },
  { "mask": 2,  "name": "REV" },
  { "mask": 48, "name": "режим", "enum": [ { "v": 0, "t": "A" }, { "v": 1, "t": "B" } ] }
]
```
`mask` — битовая маска (для одного бита степень двойки). Значение поля = `(raw & mask) >> shift`.

### `fields` — составные значения

```jsonc
{ "addr": 75, "type": "time", "count": 4, "fields": [
    { "name": "Год",    "addr": 75 },
    { "name": "Месяц",  "addr": 76, "bits": [15, 8] },
    { "name": "День",   "addr": 76, "bits": [7, 0] } ] }
```
`bits` — диапазон `[старший, младший]` внутри слова; без него берётся слово целиком.

### Условия

```jsonc
"visible_if": { "addr": 100, "in": [1, 2, 3] }      // равно / не равно / в списке / больше / меньше
"enable_if":  { "addr": 118, "eq": 0 }
"readonly_if":{ "all": [ { "addr": 100, "gt": 0 }, { "addr": 118, "eq": 0 } ] }
```
Операторы: `eq`, `ne`, `in`, `gt`, `lt`, `between`, `bit` (установлен бит маски),
плюс `all` / `any` для объединения.

## 3. Команды

Последовательности записей: пресеты, служебные операции, запись через инструкцию.

```jsonc
"commands": [
  { "id": "save", "name": "Сохранить в память", "danger": false,
    "steps": [ { "write": { "addr": 117, "value": 1 } } ],
    "confirm": [ { "addr": 117, "eq": 0 } ], "timeout_ms": 2000 },

  { "id": "s111.set_baud", "name": "Сменить скорость",
    "params": [ { "name": "baud", "type": "u16", "enum": [ { "v": 2, "t": "9600" } ] } ],
    "steps": [ { "write": { "addr": 301, "value_from": "param.baud" } },
               { "write": { "addr": 300, "value": 2 } } ] }
]
```

| Поле шага | Смысл |
|---|---|
| `write.addr`, `write.value` | записать константу |
| `write.value_from` | взять из параметра команды (`param.имя`) или из регистра (`addr:105`) |
| `delay_ms` | пауза после шага |
| `read.addr`, `read.expect` | проверка результата |

`confirm` — условия, подтверждающие выполнение (например, флаг сбросился).
`danger: true` — интерпретатор обязан спросить подтверждение.

## 4. Аварии и оформление

```jsonc
"alarms": [ { "addr": 27, "name": "Текущая ошибка", "enum": "innovert.fault" } ],

"ui": {
  "gauges": [ { "addr": 2, "label": "Частота", "unit": "Гц", "max": 60 } ],
  "charts": [ { "addr": 5, "label": "Шина DC", "period_ms": 1000 } ],
  "columns": ["name", "value", "unit", "desc"]
}
```

## 5. Что сознательно НЕ входит в формат

- **Текущие значения регистров.** Файл — статический профиль прибора; состояние
  (`addr → raw`) держит интерпретатор. Значение по умолчанию — `default`.
- **Логика опроса и подписок.** Класс опроса задаётся (`poll`), конкретные тайминги —
  дело интерпретатора.
- **Тексты интерфейса, кроме подписей регистров.** Локализация — отдельная задача.

## 6. Версионирование

`format` меняется при несовместимом изменении. Совместимые дополнения (новые необязательные
поля) версию не меняют — интерпретатор обязан игнорировать незнакомые поля и сообщать о них
предупреждением, а не падать.
