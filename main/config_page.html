список пуст
«Загрузить файл» выбирает файл на вашем компьютере, имя подставляется само — его можно поправить в поле выше. Передача идёт порциями по 6 КБ и складывается во временный файл, который встаёт на место цели лишь после последней порции: оборванная передача рабочий файл не портит, а существующий заменяется целиком. Ограничение — 500 КБ на файл. Имя файла в списке открывает его по HTTP (так же отдаются страницы и карты регистров). Каталог можно переименовать и удалить — удаляется только пустой.
